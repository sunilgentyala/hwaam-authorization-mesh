Get started

Run an authorization decision locally.

Install

git clone https://github.com/sunilgentyala/hwaam-authorization-mesh.git
cd hwaam-authorization-mesh
python -m pip install -e .

Evaluate

hwaam evaluate \
  --policy examples/policy.json \
  --request examples/request_allowed.json \
  --secret demo-secret

Run tests

python scripts/run_tests.py

Run benchmark

python scripts/benchmark.py --iterations 20000
python scripts/generate_results.py

Try denial cases

hwaam evaluate \
  --policy examples/policy.json \
  --request examples/request_cross_tenant.json \
  --secret demo-secret

The denied command exits with status code 2 so CI pipelines can distinguish enforcement failures from execution errors.
