Get started

Run an authorization decision locally.

Install

git clone https://github.com/sunilgentyala/hwaam-authorization-mesh.git
cd hwaam-authorization-mesh
python -m pip install -e .

Evaluate

hwaam evaluate \
  --policy examples/policy.json \
  --request examples/request_allowed.json \
  --secret demo-secret \
  --issuer-secret demo-issuer-secret \
  --trusted-issuers identity-provider,user:suresh

--secret signs the engine's own receipt. --issuer-secret verifies the signed security context, approvals, and delegation hops attached to the request — the engine never trusts those fields unsigned. Prefer --secret-file/--secret-env/--secret-stdin (and the matching --issuer-secret-* forms) over the bare flag outside of local testing.

Run tests

python scripts/run_tests.py

Run benchmark

python scripts/benchmark.py --iterations 20000
python scripts/generate_results.py

Try denial cases

hwaam evaluate \
  --policy examples/policy.json \
  --request examples/request_cross_tenant.json \
  --secret demo-secret \
  --issuer-secret demo-issuer-secret \
  --trusted-issuers identity-provider,user:suresh

Exit codes reflect the decision: 0 allow, 4 conditional allow (obligations still outstanding), 2 deny, 1 execution error — so a caller can't mistake a conditional allow for a clean pass, and CI pipelines can distinguish enforcement failures from execution errors.
